🛡️ Hardware Dual-Slot A/B Auto-Rollback Safety Net

The 1st-gen X1D-50c has a built-in hardware safety net in U-Boot (`IS25LQ040B` SPI NOR) and eMMC (`mmcblk3`):
  • SPI NOR U-Boot is never touched: hbl-upgrade explicitly skips flashing U-Boot.
  • Inactive slot only: If you are running on Slot A (mmcblk3p1/p2), the update formats and writes only Slot B (mmcblk3p3/p4), leaving your working OS 100% intact.
  • One-shot trial boot (upgrade=1): On reboot, U-Boot sees upgrade=1, immediately clears upgrade and saves env before booting the new slot with status=1.
  • Automatic rollback: Only after Linux + D-Bus + upgrade-daemon successfully start does hbl-post-upgrade commit current_bootpart. If the new slot fails to boot, simply power-cycling the camera boots right back into your working firmware!
