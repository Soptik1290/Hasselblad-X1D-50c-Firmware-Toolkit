# Firmware Directory (`firmware/`)

Place official Hasselblad X1D-50c (1st generation) `.cim` firmware files in this directory:

* `X1D_v1_20_0.cim` (`59,395,584` B, Build 21, `2017-12-13`)
* `X1D_v1_20_1.cim` (`59,372,032` B, Build 22, `2018-01-17`)
* `X1D_v1_21_0.cim` (`63,267,328` B, Build 28, `2018-05-02`)
* `X1D_v1_22_0.cim` (`63,388,672` B, Build 33, `2019-01-18`)
* `X1D_v1_24_0.cim` (`63,393,792` B, Build 38, `2020-01-29`)
* `X1D_v1_25_0.cim` (`63,410,176` B, Build 42, `2020-10-22`)

> Note: `.cim` binary files are ignored by `.gitignore` due to their size (~60 MB each) and copyright. See [`../docs/07-firmware-version-comparison.md`](../docs/07-firmware-version-comparison.md) for hashes and detailed comparisons.
